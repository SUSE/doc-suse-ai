= How do I upgrade {ai-app-name}?

You can upgrade {ai-app-name} either using *{ranchera}* or on the command line with *{helm}*.

[#{ai-app-string}-upgrading-rancher]
== Upgrade using {ranchera}

Refer to link:https://documentation.suse.com/suse-ai-factory/latest/html/AI-Factory-usage/ai-factory-managing-workloads.html#aif-app-workloads-upgrade[AI application upgrade] for a general upgrade procedure.

[#{ai-app-string}-upgrading-helm]
== Upgrade using {helm}

To upgrade {ai-app-name} to a specific version using {helm}, use the following command:

[,sh,subs="+attributes"]
----
{prompt_user}helm upgrade {ai-app-string} \
  oci://registry.suse.com/ai/charts/{ai-app-string} \
  -n {ai-app-string} \
  --version <VERSION_NUMBER> \ <.>
  --wait --timeout 15m \
  --force-conflicts
----
<.> If you omit `--version`, {ai-app-name} gets upgraded to the latest available version.
