[#aif-deployment-install-gpu-operator]
=== Install {nvoperator}
Install the GPU operator on the downstream clusters where GPU resources are available, and not on the management cluster where {rancher} is running.
Refer to link:https://documentation.suse.com/cloudnative/rke2/latest/en/add-ons/gpu_operators.html[GPU Operator Installation] for more details.
