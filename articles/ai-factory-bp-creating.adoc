[abstract]
--
This guide walks you through creating custom blueprints for {productname} using the command line.
Learn how to quickly adapt an existing blueprint and how to build a full multi-component stack from scratch, supporting both CPU ({ollama}) and {nvidia} GPU ({vllm}) inference.

The instructions assume an operational {kube} cluster with {ranchera} and {productname} installed (including {nvidia} GPU support if using {vllm}), and that you maintain your blueprint files in a Git repository.
--
