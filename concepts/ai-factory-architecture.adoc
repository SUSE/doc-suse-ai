[#ai-factory-foundation]
== Foundation
The base layer of {saifactory} is deployed on bare metal or cloud-hosted nodes, preferably deployed by the {ranchelemental}.
It consists of the following components:

* a prescribed configuration of the {slsa} 16 operating system
* {rke2a} {kube} management cluster
* {ranchermanager} that supports the UI extension and {kube} operator code for {saifactory}
* optionally, {ssecurity} and {sobservability} work together to provide high security and advanced monitoring capability across all AI workloads

[#ai-factory-itself]
== AI Factory
{saifactory} is a {ranchera} Dashboard extension the serves the following purposes:

* discover, install and manage individual applications from {ailibrary}
* discover, install and manage preconfigured {suse} Blueprints that bundle specific AI applications from {ailibrary} to match a target use-case
* discover, install and manage preconfigured {nvidia} Blueprints that bundle specific AI applications to match a target use-case
* create custom Blueprints based on customer's AI application selection

Both running applications and Blueprints can be shared across {ranchera}-managed clusters.
