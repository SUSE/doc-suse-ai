To install the package, run the command:

* on regular {productname}
+
----
[source,bash]

sudo zypper in kit
----
* on the immutable {productname}
+
[source,bash]
----
sudo transactional-update pkg in kit
----
+ 
and then reboot the system
+
----
[source,bash]
sudo reboot
----
