== Installing Kit

To install the package, run the command:

* on regular {productname}
+
----
[source,bash]

sudo zypper in kit
----
* on the immutable {productname}
+
[source,bash]
----
sudo transactional-update pkg in kit
----
+ 
and then reboot the system
+
----
[source,bash]
sudo reboot
----

To verify the installation, run the following command:

----
[source,bash]

kit --help
----

== Kit main configuration

The package installs the default configuration  file `.kit.yml` to your home directory if it is not already present. It is the primary declarative configuration file for the Kit AI agent. Its purpose is to persist your preferred LLM provider settings, generation parameters, system prompts, and external Model Context Protocol (MCP) server connections so you do not have to pass them via CLI flags or environment variables on every run.

The default location of the file in your home directory is applied across the system as the baseline configuration. You can also place the configuration file to other locations:

* Project-local:: When placed in a working directory it overrides the default one in your home directory. This path is ignored if when `kit` is run with the `--bare` option.
* Custom path:: You can pass a specific path to Kit using the `--config <path>` option. This option overrides the default configuration file.
