To install the package, run the command:

* on regular {productname}
+
----
[source,bash]

sudo zypper in kit
----
* on the immutable {productname}
+
[source,bash]
----
sudo transactional-update pkg in kit
----
+ 
and then reboot the system
+
----
[source,bash]
sudo reboot
----

To verify the installation, run the following command:

----
[source,bash]

kit --help
----

Besides the Kit binary, the package installs the default configuration `.kit.yml` to your home directory. The default configuration disables tools provided by Kit.
