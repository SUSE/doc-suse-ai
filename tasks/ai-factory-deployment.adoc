== Installation using {saifoperator}

. Install the {saioperator}:
+
[source,bash,subs="+attributes"]
----
{prompt_user}helm install aif-operator \ <.>
  oci://ghcr.io/suse/chart/aif-operator:0.1.0-dev.1 \
  --namespace aif-operator \
  --create-namespace
----
<.> Modify the namespace to match your needs.
