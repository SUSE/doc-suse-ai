[#aif-app-workloads-manage]
== How do I manage application workloads?
. From the main left panel, select menu:SUSE AI Factory[Workloads].
. Select the btn:[Manage] button pertaining to the application workload you want to manage.
. In the `Manage` wizard, you can update the application version, the destination cluster, and the details of the {helm} chart.
. Confirm with btn:[Save].

[#aif-app-workloads-upgrade]
== How do I upgrade application workloads?
. From the main left panel, select menu:SUSE AI Factory[Workloads].
. Select the btn:[Manage] button pertaining to the application workload you want to upgrade.
. On the `Basic Information` screen, change the target version number.
. Finish the wizard and the workload upgrade starts automatically.

[#aif-bp workloads-upgrade]
== How do I upgrade blueprint workloads?
. From the main left panel, select menu:SUSE AI Factory[Workloads].
If a blueprint workload has an upgrade candidate, a corresponding btn:[Upgrade] button will appear on its row.
. Select the btn:[Upgrade] button pertaining to the blueprint workload you want to upgrade.
After confirming the upgrade, the workload transitions through a `Pending` state while the updated applications are redeployed.
Once the rollout completes, the workload returns to `Running` state at the new version.
+

[#aif-workloads-delete]
== How do I delete workloads?
. From the main left panel, select menu:SUSE AI Factory[Workloads].
. Select the btn:[Delete] button pertaining to the you want to uninstall, and confirm the deletion.
