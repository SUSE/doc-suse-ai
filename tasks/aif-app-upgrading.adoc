[#{ai-app-string}-upgrading-rancher]
== Upgrading with {ranchera}

Refer to link:https://documentation.suse.com/suse-ai-factory/latest/html/AI-Factory-usage/ai-factory-managing-workloads.html#aif-app-workloads-upgrade[AI application upgrade] for a general upgrade procedure.

[#{ai-app-string}-upgrading-helm]
== Upgrading with {helm}

. Log in to {ai-app-registry}.
To prevent the password from being stored in the shell history, save it to the `password.txt` file.
+
[,sh,subs="+attributes"]
----
ifeval::["{ai-app-registry}" == "{sregistry}"]
{prompt_user}helm registry login registry.suse.com \
  --username=regcode \
endif::[]
ifeval::["{ai-app-registry}" == "{sappco}"]
{prompt_user}helm registry login dp.apps.rancher.io \
  --username=<APPCO-USERNAME> \
endif::[]
  --password-stdin < password.txt
----

. Upgrade {ai-app-name}.
+
[,sh,subs="+attributes"]
----
{prompt_user}helm upgrade {ai-app-string} \
ifeval::["{ai-app-registry}" == "{sregistry}"]
  oci://registry.suse.com/ai/charts/{ai-app-string} \
endif::[]
ifeval::["{ai-app-registry}" == "{sappco}"]
  oci://dp.apps.rancher.io/charts/{ai-app-string} \
endif::[]
  -n {ai-app-string} \
  --version <VERSION_NUMBER> \ <.>
  --wait --timeout 15m \
  --force-conflicts
----
<.> If you omit `--version`, {ai-app-name} gets upgraded to the latest available version.
