[#aif-bp-creating-readme]
== Creating the README file

Every blueprint must include a `README.md` providing clear instructions and architectural context. Structure the file according to the standard blueprint template:

[source,markdown]
----
# My Demo (Ollama) — SUSE AI Factory blueprint

Deploys a multi-component demo featuring **Ollama** and **Qdrant**.

Blueprint CR: [`my-demo-ollama-1-0-0.yaml`](my-demo-ollama-1-0-0.yaml)

[#aif-bp-creating-attribution]
== Providing attribution

If a blueprint derives from an upstream open source project, add an `ATTRIBUTION.md` file detailing:

* Reused components and modifications.
* Upstream repository URL and SPDX license identifier.
* Chart and model license requirements (for example, models with non-commercial license terms).

Link to `ATTRIBUTION.md` from the lead section of `README.md`.
