To uninstall {productname}, you need to perform the following tasks:

* Optionally, back up configuration, secrets and custom resources.
* Uninstall {saifoperator}.
* Remove installation leftovers.
* Optionally, remove Custom Resource Definitions (CRDs).

You can uninstall {productname} either using {ranchera} or the command line.

[NOTE]
.What uninstalling removes
====
Uninstalling the operator chart removes the bundled blueprints, the {suse} partner blueprint catalog, and the UI extension.
The CRDs, the `Settings` resource, and the `aif-ui-config` ConfigMap of the UI extension are deliberately retained so that a reinstallation preserves your configuration and existing workload resources.

Remove them explicitly with the steps below if you want a complete removal.
====

[#{root-section-id}aif-uninstall-backup]
== Back up {productname} resources and configuration (optional)

Before uninstalling {productname}, back up your configuration, secrets and custom resources to preserve them for future use or reinstallation:

. *Back up {helm} chart values*
+
Export the values used to deploy `{saifoperator}`:
+
[source,console,subs="+attributes"]
----
{prompt_user}helm get values aif-operator -n aif-operator -a > aif-operator-values-backup.yaml
----

. *Back up settings*
+
Export the `Settings` custom resource in the `aif-operator` namespace:
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl get settings settings -n aif-operator -o yaml > aif-settings-backup.yaml
----

. *Back up secrets*
+
Export all secrets (including registry credentials, Git access tokens, and CA certificates) configured in the `aif-operator` namespace:
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl get secrets -n aif-operator -o yaml > aif-secrets-backup.yaml
----

. *Back up UI extension configuration*
+
Export the `aif-ui-config` ConfigMap from the `cattle-ui-plugin-system` namespace:
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl get configmap aif-ui-config -n cattle-ui-plugin-system -o yaml > aif-ui-config-backup.yaml
----

. *Back up {productname} custom resources*
+
Export all existing blueprints, blueprint catalogs, AI workloads, and extension install resources:
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl get blueprints,blueprintcatalogs,aiworkloads,installaiextensions -A -o yaml > aif-cr-backup.yaml
----

[#{root-section-id}aif-uninstall-helm]
== Uninstall using {helm}

. *Uninstall {saifoperator}*
.. Uninstall the {saifactory} extension and the operator.
+
[source,console,subs="+attributes"]
----
{prompt_user}helm uninstall aif-operator -n aif-operator
----

.. Verify that the resources have been removed by running the following commands.
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl get all -n aif-operator
{prompt_user}kubectl get aifext
{prompt_user}helm list -n aif-operator
----

. *Remove installation leftovers*
.. Remove the related settings resource.
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl delete settings settings -n aif-operator
----
.. Remove the configuration of the UI extension.
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl delete configmap aif-ui-config -n cattle-ui-plugin-system
----

. To perform a complete removal of all resources, *remove CRDs*.
.. Delete {productname} CRDs.
+
[source,console,subs="+attributes"]
----
{prompt_user}kubectl delete crd \
  aiworkloads.ai-factory.suse.com \
  blueprintcatalogs.ai-factory.suse.com \
  blueprints.ai-factory.suse.com \
  installaiextensions.ai-factory.suse.com \
  settings.ai-factory.suse.com
----

[#{root-section-id}aif-uninstall-rancher]
== Uninstall using {ranchera}

. *Uninstall the {saifactory} extension and the operator.*
.. From the main left panel, select the cluster you want to uninstall from, then menu:Apps[Installed Apps].
.. From the list of installed applications, activate the checkbox of `aif-operator` and click btn:[Delete] above the list.
+
[#{root-section-id}fig-aif-uninstall]
.Uninstalling {saifoperator}
image::aif-operator-uninstall.png[Screenshot showing how to uninstall {saifoperator},scaledwidth=100%]
.. Confirm the deletion and wait until it is finished.

. *Remove installation leftovers*
.. From the same cluster menu, select menu:More Resources[ai-factory.suse.com > Settingses].
.. Activate the checkbox of `aif-operator` and click btn:[Delete] above the list.
+
[#{root-section-id}fig-aif-leftovers-uninstall]
.Uninstalling {saifoperator} leftovers
image::aif-leftovers-uninstall.png[Screenshot showing how to uninstall {saifoperator} leftovers,scaledwidth=100%]
.. Confirm the deletion.
.. From the same cluster menu, select menu:Storage[ConfigMaps].
.. Activate the checkbox of `aif-ui-config` in the `cattle-ui-plugin-system` namespace and click btn:[Delete] above the list.
.. Confirm the deletion.

. To perform a complete removal of all resources, *remove CRDs*.
.. From the same cluster menu, select menu:More Resources[API > CustomResourceDefinitions].
.. Filter the list by entering `ai-factory.suse.com` in the search box.
.. Activate the checkbox of all `ai-factory.suse.com` resources and click btn:[Delete] above the list.
+
