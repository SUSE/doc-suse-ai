*{fleeta} Bundle*::
Deploy the application directly as a {fleeta} bundle managed by {rancherfleet} (https://fleet.rancher.io/0.12/).
Suitable for users who want to use {fleeta} without maintaining a separate Git repository.

*Publish to {fleeta} Git*::
Publish the application configuration to a Git repository monitored by {fleeta}.
{fleeta} automatically deploys and reconciles the application using a GitOps workflow.

*{helm}*::
Deploy the application using {helm} commands or the {ranchera} Apps UI.
Suitable for direct installation and manual lifecycle management.
