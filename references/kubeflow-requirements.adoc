Storage class::
All PVCs use the cluster default StorageClass unless `global.storageClass` is set.
For single-node clusters the Local Path Provisioner is sufficient for development. For production, Longhorn is recommended.
+
[NOTE]
====
Make sure a default StorageClass is set for the cluster before installing.
Run `kubectl get storageclass` and confirm that one has the (default) designation next to its name.
Otherwise, designate one, for example:

[,sh,subs="+attributes"]
----
{prompt_user}kubectl patch storageclass local-path \
  -p '{"metadata": {"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'
----
====

Cloudflare API token::
Only required if you want automatic DNS record management via `external-dns` or Let's Encrypt DNS-01 challenges.
