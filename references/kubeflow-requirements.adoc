[#kubeflow-requirements-hardware]
== Hardware requirements

|===
| Profile | CPU | RAM | GPU | Storage

| Minimal evaluation
| 8 cores
| 16 GB
| None
| 100+ GB

| Recommended evaluation
| 8-18 cores
| 32-64 GB
| 1 GPU
| 250+ GB

| Production / large language model development
| 16+ cores
| 64-128+ GB
| 2+ GPUs (workload-dependent)
| 500+ GB
|===

|===

| >= 4.0

| {certmanager}
| 1.19.3

| 1.1.3

| —

| {sregistry} credentials
| —
| User name + token for `registry.suse.com` (suse-ai-registry secret) — required when sub-charts pull from {sregistry}
|===

Cloudflare API token::
Only required if you want automatic DNS record management via `external-dns` or Let's Encrypt DNS-01 challenges.
Not needed for basic installs.
